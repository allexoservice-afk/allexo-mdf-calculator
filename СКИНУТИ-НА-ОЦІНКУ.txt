Ти не зобов’язаний нічого викладати в інтернет і не зобов’язаний відкривати
сайт у браузері. Для оцінки зазвичай достатньо одного з варіантів нижче.


--------------------------------------------------------------------------------
  ВАРІАНТ 1 — найзручніше для програміста (код + структура)
--------------------------------------------------------------------------------

Надішли другу АРХІВ УСЬОГО ПРОЄКТУ (але без папки node_modules — вона важка
і з неї все одно збирають заново).

Що друг робить САМ у себе (якщо захоче глянути в браузері — це вже його вибір):
  розпакувати → npm install → npm run dev

Тобі для оцінки «на словах» достатньо скинути архів — ти нічого не запускаєш.


--------------------------------------------------------------------------------
  ВАРІАНТ 2 — репозиторій Git (GitHub / GitLab / інше)
--------------------------------------------------------------------------------

Якщо проєкт уже в хмарі — надішли посилання на репозиторій. Друг дивиться код
у браузері на GitHub або клонує собі. Ти знову нічого не запускаєш.


--------------------------------------------------------------------------------
  ВАРІАНТ 3 — тільки вигляд, без коду (якщо друг не лізе в проєкт)
--------------------------------------------------------------------------------

Зроби кілька СКРІНШОТІВ екрану (головна, калькулятор, підсумок) і скинь
картинками. Це для думки «як виглядає», а не для рев’ю коду.


--------------------------------------------------------------------------------
  Як швидко зібрати архів проєкту для надсилання (у себе в терміналі)
--------------------------------------------------------------------------------

З папки проєкту (де лежить package.json):

  zip -r allexo-mdf-calculator-for-friend.zip . \
    -x "node_modules/*" -x ".pnpm-store/*" -x "dist/*" -x ".git/*" -x "*.zip"

  Або одним рядком (з кореня проєкту):

  bash scripts/zip-project-for-review.sh

Утвориться файл allexo-mdf-calculator-for-friend.zip — його і надсилай.
  (Можеш перейменувати як зручно; уникай пробілів у назві — так простіше в терміналі.)

(Якщо команди zip немає — можна вручну: зіпнути всю папку проєкту, але
 НЕ включай папки node_modules, .pnpm-store, dist і .git — так архів буде малий.)
