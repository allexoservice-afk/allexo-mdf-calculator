ALLEXO — фірмовий набір логотипів
==================================

Кольори (як на сайті):
  Teal:  #0f3d3e
  Gold:  #c4a35a
  Cream: #e8dcc0

SVG (вектор, для друкарні / винилу / масштабування):
  brand/svg/allexo-icon.svg           — квадратна іконка (Facebook, наклейки)
  brand/svg/allexo-horizontal.svg     — горизонтальний напис (світлий фон)
  brand/svg/allexo-horizontal-light.svg — горизонтальний напис (темний фон, авто)
  brand/svg/allexo-stacked.svg        — іконка + напис (футболки)
  brand/svg/allexo-badge.svg          — повний бейдж з фоном (борт авто, вивіска)

PNG (готові розміри):
  brand/png/facebook-profile-512.png  — фото профілю Facebook / Instagram
  brand/png/facebook-cover-1600.png   — обкладинка (можна обрізати до 820×312)
  brand/png/tshirt-stacked-1800.png   — футболка (груди / спина)
  brand/png/car-horizontal-2400.png   — авто, світла наклейка
  brand/png/car-horizontal-light-2400.png — авто, темний кузов
  brand/png/vehicle-badge-3000.png    — великий бейдж на бік фургона
  brand/png/print-horizontal-3600.png — висока якість для друку
  brand/png/icon-print-1800.png       — іконка для вишивки / термодруку

Перегенерувати PNG:
  pnpm run export:brand-logos

Рекомендації:
  • Facebook профіль → facebook-profile-512.png
  • Facebook обкладинка → facebook-cover-1600.png
  • Футболка (біла) → tshirt-stacked-1800.png або allexo-horizontal.svg
  • Футболка (темна) → allexo-horizontal-light.svg
  • Машина → car-horizontal-light-2400.png (темний кузов) або vehicle-badge-3000.png

Для професійного друку на авто передайте друкарні файл SVG з папки brand/svg/.
