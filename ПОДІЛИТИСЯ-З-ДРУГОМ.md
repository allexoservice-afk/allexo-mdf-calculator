# Як показати калькулятор другу

## Варіант 1 — посилання в інтернеті (найзручніше для друга)

Друг **нічого не встановлює**, просто відкриває посилання в браузері.

1. У себе на комп’ютері в папці проєкту виконай у терміналі:
   ```bash
   npm install
   npx vite build
   ```
   З’явиться папка **`dist`** — це готовий сайт.

2. Зайди на **[Netlify Drop](https://app.netlify.com/drop)** (потрібен безкоштовний акаунт Netlify або швидка реєстрація).

3. **Перетягни всю папку `dist`** у вікно браузера на сторінці Drop.

4. Netlify видасть посилання виду `https://випадкова-назва.netlify.app` — **скопіюй і надішли другу** в Telegram / Viber / пошту.

Після змін у коді: знову `npx vite build` і можна перезалити нову версію `dist` (у Netlify є «Deploys» — оновлення).

---

## Варіант 2 — архів для друга-програміста

Якщо друг **вміє з Node.js**:

1. У корені проєкту вже може лежати архів **`allexo-calculator-dist-for-friend.zip`** (папка `dist` запакована). Надішли йому файл.

2. Він розпаковує архів, заходить у розпаковану папку і запускає:
   ```bash
   npx serve .
   ```
   Відкриває в браузері адресу, яку покаже `serve` (зазвичай `http://localhost:3000`).

**Не варто** просто подвійним кліком відкривати `index.html` з диска — у багатьох браузерах такий сайт **не запуститься** через обмеження без локального сервера.

## Варіант 3 — весь код (Git)

Якщо проєкт у **GitHub / GitLab** — надішли посилання на репозиторій. Друг клонує, робить `npm install` і `npm run dev` — побачить сайт з автоматичним оновленням під час розробки.

```bash
git clone <посилання-на-репо>
cd allexo-mdf-calculator
npm install
npm run dev
```

У терміналі з’явиться локальна адреса (наприклад `http://localhost:5173`).

---

## Швидко зібрати ZIP у себе

З кореня проєкту:

```bash
npm install
npx vite build
cd dist && zip -r ../allexo-calculator-dist-for-friend.zip . && cd ..
```

Файл **`allexo-calculator-dist-for-friend.zip`** можна відправити поштою або в месенджері (обмеження розміру файлу — залежить від сервісу).
